DATABASE SCHEMA:
================

users table:
  - id (uuid, PK)
  - email (unique)
  - password_hash (bcrypt)
  - is_guest (boolean)
  - created_at (timestamp)

records table:
  - id (uuid, PK)
  - user_id (FK, indexed)
  - title (text)
  - category (text, indexed)
  - value (numeric)
  - timestamp (timestamp, indexed)
  - metadata (JSON)
  - created_at, updated_at

background_data table:
  - id (uuid, PK)
  - source_url (text)
  - data (JSON)
  - fetched_at (timestamp, indexed DESC)
  - status (text)
  - error_message (text)
